# 商品台帳(人が更新します。担当は書き換えません)

提携済み・紹介してよい商品を、下の形式で追加してください。
ここに「提携状況=済」の商品があれば、毎朝の投稿案はその中から作ります。
無い場合は、商品選び担当が候補と公式情報を集め、「下書き」として出します。

## 記入例(削除して使ってください)
## 商品: 品名・型番
- 提携状況: 済 / 未 / 要確認
- ASP・規約メモ: (禁止事項、素材の条件、PR表記の指定など)
- 利用状況: 使用済み(期間・感想メモ) / 未使用
- 公式情報(確認日 YYYY-MM-DD, URL): 価格/サイズ/素材/耐荷重/特典
- 公式で確認できる注意点:
- 使って分かった良い点・気になった点: (使用済みのみ。ここに書いた範囲だけを体験として投稿に使います)
- 使ってよい素材: (公式提供の画像など)
