# アフィリエイト運用リポジトリ

毎朝の投稿案づくりと週次の振り返りが、この中のファイルを読み書きします。

- `CLAUDE.md` … 運用ルール(ジャンル・口調・NG表現・PR表記)
- `.claude/agents/` … 7人の担当の定義
- `scripts/lint_posts.py` … 投稿案の機械チェック
- `config/products.md` … 商品台帳(人が更新)
- `output/` … 日次の投稿案・チェック結果・insights.md(自動で追加)
- `data/` … クリック・成約のCSV(人が置く)

## 最初の設定
1. このフォルダの中身を、GitHubの**非公開**リポジトリに置く
2. Claudeにそのリポジトリを接続する
3. 定期実行(毎朝・毎週)の指示文を、リポジトリを読む形に切り替える
